# Pyramis-L3D Three-Stage Codebook Fix — LaTeX Compile Guide

Outputs `paper.pdf` (arXiv technical report draft).

## Files
- `paper.tex` — main source. Uses standard `article` class + natbib (no custom `.sty` required, compiles anywhere).
- `paper.bib` — BibTeX references. Uses `\bibliographystyle{apalike}` (natbib apalike, built-in).

## Prerequisites
Any standard TeX Live / MacTeX / MiKTeX. Required packages (all CTAN standard, no non-free repos):
```
geometry, inputenc, fontenc, natbib, hyperref, booktabs,
multirow, graphicx, amsmath, amssymb, bm, xcolor
```

## Compile
### Option A: latexmk (recommended, one-shot)
```bash
cd paper/
latexmk -pdf -bibtex paper.tex
```
Produces `paper.pdf` in the same folder.

### Option B: manual (no latexmk)
```bash
cd paper/
pdflatex paper.tex
bibtex   paper
pdflatex paper.tex
pdflatex paper.tex
```
You need the three `pdflatex` passes to resolve references and citations.

## Verify
```bash
pdftotext paper.pdf - | head -30
# Should show title "Hierarchical VQ-KV with Gradient-Flow Recovery..."
# plus the abstract with "three-stage ablation" and "PPL...1.018" keywords.
```

## For arXiv submission
Package everything into one `.zip` with the following layout (arXiv auto-compiles):
```
paper.tex
paper.bib
paper.bbl      (generated by bibtex, RECOMMENDED to include so arXiv skips bibtex)
```
To generate `paper.bbl`: compile locally first, then copy `paper.bbl` alongside `paper.tex`.
arXiv sometimes has BibTeX version issues; shipping the `.bbl` bypasses them entirely.

## Troubleshooting
- `LaTeX Error: File xxx.sty not found` → install the missing package via your OS
  TeX package manager (Deb/Ubuntu: `apt install texlive-latex-extra texlive-science
  texlive-bibtex-extra`, macOS/MacTeX: `sudo tlmgr install xxx`).
- Citations show `[?]` → you forgot a `pdflatex` pass, or the citation key doesn't
  match `paper.bib`. Re-run bibtex and check for `Warning--I didn't find a database
  entry for` in `paper.blg`.
- Hyperref color is too bright for print → change `\hypersetup{colorlinks,...}` to
  `\hypersetup{colorlinks=false, pdfborder={0 0 0}, ...}` before submission.
